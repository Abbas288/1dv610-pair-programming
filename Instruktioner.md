## Lösenordsgenerator
Kontext: Säkerhetsverktyg för att skapa och bedöma lösenord.

Som användare vill jag ange längd och teckentyper (bokstäver/siffror/specialtecken) och få ett slumpat lösenord.
Som användare vill jag mata in ett befintligt lösenord och få en bedömning av dess styrka.
Som användare vill jag kunna generera flera lösenordsförslag på en gång.
Som användare vill jag kunna generera ett uttalbart lösenord (t.ex. genom att slumpa ihop stavelser) som är lättare att komma ihåg.
(Stretch) Som användare vill jag varnas om mitt lösenord innehåller vanliga mönster (t.ex. "123", "qwerty").
