# Uppgift

Det här är vad vi ska göra under workshopen.

## Lösenordsgenerator

**Kontext:** Säkerhetsverktyg för att skapa och bedöma lösenord.

### User Stories
Applikationens krav är skrivna som user stories.

#### US1: Generera lösenord
Som användare vill jag ange längd och teckentyper (bokstäver, siffror och specialtecken) och få ett slumpat lösenord.

#### US2: Bedöma lösenordsstyrka
Som användare vill jag mata in ett befintligt lösenord och få en bedömning av dess styrka.

#### US3: Generera flera lösenord
Som användare vill jag kunna generera flera lösenordsförslag på en gång.

#### US4: Generera uttalbart lösenord
Som användare vill jag kunna generera ett uttalbart lösenord, till exempel genom att slumpa ihop stavelser, som är lättare att komma ihåg.

#### US5: Varna för vanliga mönster
**Stretch goal**

Som användare vill jag varnas om mitt lösenord innehåller vanliga mönster, till exempel `123` eller `qwerty`.
